Guide

Generate a local static blog

1. Configure folders

Set a local content folder and a local public output folder in the Configuration screen. 

contentDir = site/content
publicDir = site/public

2. Configure the site

Use the Site screen to set the title, description, header links, footer text, footer links, and Styxpress watermark.

3. Write posts

Create Markdown posts in the Posts screen. Save drafts, preview rendered HTML, then publish a post when it should be included in public output.

4. Render output

Use Render site to write the static homepage, post pages, feed, sitemap, stylesheet, covers, and assets into the public folder.
